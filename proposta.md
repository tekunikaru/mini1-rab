# Mini Projeto 1 - Web Scrapers

Desenvolva um Web Scrapers do tema que você quiser.
Publicar aqui o somente link do seu projeto no seu github.
Não se esquecer:

- O código-fonte
- O arquivo com as dependências do projeto ( requirements.txt)
- O arquivo README.md, contendo um breve descritivo do projeto, um guia de como reproduzir o seu projeto na máquina de quem está visitando seu projeto.

O tema do seu web scrapers é livre: Busca de notícias em um portal, busca de informações sobre Pokemon, etc..
